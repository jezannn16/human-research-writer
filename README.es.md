# Human Research Writer

[English](README.md) · [Русский](README.ru.md) · [Español](README.es.md)

**Haz que la investigación se lea con claridad y criterio.**

Una habilidad para redactar textos académicos naturales basados en fuentes verificables, con reglas de estilo y una revisión transparente.

## Qué hace

Ayuda a escribir y revisar trabajos, capítulos, secciones y tablas. Responde en el idioma solicitado por el usuario.

## Cómo funciona

Vincula hechos con fuentes, distingue el análisis propio y elimina fórmulas vacías y símbolos decorativos, conservando citas y formato.

## Requisitos

La auditoría independiente requiere la versión Luna más reciente disponible con razonamiento medio. Si no está disponible, el resultado se marca como borrador. El verificador de estilo requiere Python.

## Instalación

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/jezannn16/human-research-writer.git ~/.agents/skills/human-research-writer
```

## Base de investigación

La habilidad se inspira en el estudio de Russell y colaboradores [StoryScope](https://arxiv.org/abs/2604.03136v6). El artículo estudia narraciones de ficción; aplicarlo a la escritura académica es una adaptación, no un resultado validado. La habilidad no promete identificar autores ni superar detectores de IA.
