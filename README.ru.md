# Human Research Writer

[English](README.md) · [Русский](README.ru.md) · [Español](README.es.md)

**Пусть исследование читается так, будто автор действительно разобрался в теме.**

Навык для ясного и естественного академического текста с проверяемыми источниками, конкретными правилами стиля и прозрачной проверкой.

## Что делает

Помогает писать и редактировать курсовые, главы, разделы и таблицы. Пишет на языке запроса или указанном пользователем языке.

## Как работает

Связывает факты с источниками, отделяет анализ от заимствованных утверждений и убирает шаблонные обороты и декоративные символы.

## Требования

Для независимого аудита требуется новейшая доступная Luna с reasoning medium. Без неё результат обозначается как черновик. Для проверки стиля нужен Python.

## Установка

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/jezannn16/human-research-writer.git ~/.agents/skills/human-research-writer
```

## Пример запроса

> Используя приложенные источники, напиши одну главу ясным естественным языком и приведи ссылки.

Полный порядок работы описан в [SKILL.md](SKILL.md) и [references/](references/).

## Исследовательская основа

В основу рекомендаций положена статья Russell и соавторов [StoryScope](https://arxiv.org/abs/2604.03136v6). Она изучает художественные рассказы; перенос наблюдений на академическое письмо является адаптацией, а не подтверждённым результатом. Навык не обещает определять авторство или обходить детекторы ИИ.
